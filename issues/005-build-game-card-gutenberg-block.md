# Build Game Card Gutenberg block

## Summary
Create a `wp-game-library/game-card` block with search, select, and render flow.

## Background
The block is the primary editor UX for adding and displaying games.

## Acceptance Criteria
- [ ] User can search for a game from the block UI
- [ ] User can select a result and persist a `game` entry
- [ ] Block renders game card details in editor and frontend
