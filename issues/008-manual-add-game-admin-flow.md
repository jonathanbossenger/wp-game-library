# Implement manual “Add Game” admin flow

## Summary
Support adding a game from wp-admin by searching IGDB and saving to library.

## Background
MVP requires a non-block workflow for admins who manage entries directly.

## Acceptance Criteria
- [ ] Admins can trigger IGDB search from game management UI
- [ ] Selecting a result creates/populates a `game` post
- [ ] Duplicate handling prevents accidental duplicate entries
